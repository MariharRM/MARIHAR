Qu'est-ce que MARIHAR ?

Votre outil de téléchargement vidéo moderne et puissant

Notre Mission

MARIHAR est né d'une volonté simple : rendre le téléchargement de vidéos accessible à tous, sans compromis sur la qualité. Nous croyons que vous devriez pouvoir profiter de votre contenu préféré, partout et à tout moment.

Technologie de Pointe

Basé sur yt-dlp, la référence mondiale du téléchargement vidéo, MARIHAR offre une interface moderne et intuitive tout en conservant toute la puissance de l'outil en ligne de commande.

Sécurité & Confidentialité

Vos données restent vos données. MARIHAR fonctionne localement sur votre machine. Aucune information n'est envoyée sur des serveurs externes, garantissant votre confidentialité totale.

Multilingue

Extraire les vidéos dans n'importe quelle langue. MARIHAR détecte automatiquement toutes les pistes audio et sous-titres disponibles pour une expérience personnalisée.

Fonctionnalités Clés

✓ Téléchargement jusqu'en 4K
✓ Extraction audio MP3 haute qualité
✓ Sous-titres multilingues
✓ Incrustation de sous-titres
✓ Téléchargement de sections
✓ Interface moderne et intuitive

Mise à jour & Configuration yt-dlp

Gérez votre version de yt-dlp et configurez votre téléchargeur vidéo

Qu'est-ce que yt-dlp ?

yt-dlp est le moteur de téléchargement vidéo le plus puissant et le plus à jour au monde. C'est lui qui permet à MARIHAR de télécharger des vidéos depuis YouTube, TikTok, Instagram et des centaines d'autres plateformes.

Pourquoi mettre à jour ?

Les plateformes de vidéo changent constamment leurs algorithmes et protections. Une mise à jour régulière de yt-dlp garantit que vous pouvez toujours télécharger vos vidéos préférées sans erreurs.

Version personnalisée

Vous pouvez utiliser votre propre version de yt-dlp si vous le souhaitez. C'est utile si vous avez besoin de fonctionnalités spécifiques ou si vous préférez gérer vous-même les mises à jour.

Configuration simple

Le menu de configuration yt-dlp vous permet de mettre à jour, choisir une version personnalisée ou réinitialiser à la version par défaut en quelques clics. Tout est conçu pour être simple et intuitif.

Étapes d'utilisation

1 Cliquez sur l'icône de configuration yt-dlp dans la barre de navigation
2 Choisissez "Mise à jour automatique" pour mettre à jour votre version actuelle
3 Choisissez "Sélectionner un fichier yt-dlp personnalisé" pour utiliser votre propre version
4 Choisissez "Réinitialiser par défaut" pour revenir à la version intégrée

Conseils importants

✓ Mettez à jour yt-dlp régulièrement pour éviter les erreurs de téléchargement
✓ La mise à jour automatique est bloquante, attendez qu'elle se termine
✓ Utilisez la version intégrée si vous n'avez pas besoin de fonctionnalités spéciales
✓ Les logs de mise à jour sont affichés dans une fenêtre de console

Comment utiliser MARIHAR ?

Guide étape par étape pour maîtriser toutes les fonctionnalités

1

Lien ou Recherche

Collez l'URL d'une vidéo ou saisissez simplement un titre pour effectuer une recherche, comme sur un moteur de recherche. Utilisez le bouton "Coller" pour récupérer une URL depuis votre presse-papiers.

Astuce : MARIHAR fonctionne avec les liens, les titres de chansons/artistes et même les playlists multi-plateformes.
2

Analyser la vidéo

Cliquez sur le bouton "ANALYSER" pour récupérer toutes les informations sur la vidéo. MARIHAR détectera automatiquement :

  • Toutes les qualités vidéo disponibles (de 144p à 4K)
  • Toutes les pistes audio (différentes langues)
  • Tous les sous-titres disponibles
  • Les formats combinés (vidéo + audio intégrés)
3

Choisir vos formats

Sélectionnez les formats qui vous conviennent :

  • Vidéo : Choisissez la résolution (720p, 1080p, 4K...)
  • Audio : Sélectionnez la langue souhaitée
  • Sous-titres : Cochez les langues à télécharger
Conseil : Les formats combinés sont recommandés pour une lecture directe sans problème de synchronisation.
4

Options avancées (optionnel)

Personnalisez votre téléchargement avec les options avancées :

  • Incruster les sous-titres : Intégrez les sous-titres directement dans la vidéo
  • Extraire l'audio : Téléchargez uniquement la piste audio en MP3
  • Section : Téléchargez uniquement une partie de la vidéo
5

Télécharger

Cliquez sur le bouton "TÉLÉCHARGER" et patientez pendant le téléchargement. Une barre de progression vous indiquera l'avancement en temps réel.

Une fois terminé, votre fichier sera disponible dans la section "Fichiers téléchargés".

Questions fréquentes

Quels sites sont supportés ?

MARIHAR supporte YouTube, Facebook, Instagram, TikTok, Twitter et des centaines d'autres plateformes via yt-dlp.

Le téléchargement est-il légal ?

Le téléchargement est autorisé pour un usage personnel. Respectez toujours les droits d'auteur et les conditions d'utilisation des plateformes.

Puis-je télécharger des playlists ?

Oui ! Collez simplement l'URL d'une playlist et MARIHAR analysera toutes les vidéos qu'elle contient.
